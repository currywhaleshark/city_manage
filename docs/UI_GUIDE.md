# UI Guide

## 통합 도시의 정책 선택과 작은 화면 (2026-10-19)

정책 목록은 행동·비용·핵심 영향을 먼저 보여 준다. 실제 남은 예산과 시행 여부, 면적·용도에 맞는 빈 공터를 확인해 **예산 15 부족**, **지을 수 있는 공터 없음**, **시행 중**을 선택 전에 표시한다. 조건이 부족한 버튼에도 키보드로 초점을 두어 이유를 읽을 수 있지만 지도 선택이나 예산 사용은 시작되지 않는다. 운영 예산이 들어오면 목록의 상태만 갱신하고 초점과 펼친 설명은 유지한다.

정책의 **주의할 점**을 펼치면 부작용을 읽을 수 있고, 적용 장소를 고른 뒤 시행 직전에도 자세한 설명과 부작용을 보여 준다. 주민 말풍선은 인용문과 똑같은 ‘바라는 점’만 생략한다. 별도의 의견, 관찰한 사실과 변화는 남긴다.

작은 화면에서도 왼쪽 지도 버튼의 아이콘과 이름을 함께 표시하며 낮은 화면에서는 목록만 세로로 스크롤한다. 시간 조작과 저장 버튼은 최소 44px 높이, 일시정지는 44×44px로 지정한다. 변경된 CSS의 실제 모바일 겹침·터치 조작은 브라우저 접근 제한으로 아직 확인하지 못했다.

## 수질오염 조사

**동네 소식 → 다른 도시 문제 → 강 아래쪽 물은 왜 더러울까요?**를 선택한다. 상류·배출구 아래·하류 표식을 누르고 **이 지점 조사하기**로 공통 수첩에 자료를 담는다. 수질 색과 물 위 봉투는 서로 다른 자료이며 왼쪽 수질 도구에서 색을 켜고 끈다. 유입구별 발생·처리와 주민 의견은 필요할 때 펼친다.

정책 카드에서 배출구 처리·생활하수 시설·하천변 청소를 고른 뒤 지도에서 적용 지점을 선택한다. 처리 시설은 연결된 하수관과 144㎡ 공터 사용을 표시한다. 5분씩 세 차례 관찰하고 결과의 지점별 수치와 하류 변화 시점을 비교한다. 수질 기록만 v7이며 이전 v3~v6도 계속 연다. [모형과 화면의 의미](WATER.md)

## 무단투기 조사

**동네 소식 → 다른 도시 문제 → 치웠는데 또 쌓이는 쓰레기**를 선택한다. 지도 현장을 누르고 **이 현장 조사하기**로 자료·주민 의견·선택 근거·수정안을 담는다. 청소·지정 배출 장소·안내 활동은 정책 카드 선택 후 지도에서 적용 위치를 정한다. 세 번의 5분 관찰 사이에 자료를 담고 재생으로 이어 간다. 현황 창은 다음 관찰 지점까지 빠르게 계산할 수 있다. 결과에서 재발·넘침·기존 수거장의 변화와 회차별 표를 비교한다. [자세한 규칙](DUMPING.md)

## 조사 수첩과 불법주차 추가

하단 **우리 동네 조사**에서 현장 찾기 → 원인 조사 → 의견 듣기 → 해결책 결정 → 시행·비교 → 수정 제안을 한 단계씩 연다. 자료와 의견은 학생이 직접 담고, 체크한 근거와 선택 이유를 정책 시행 시점에 보존한다. 수첩을 여는 동안 시간은 멈춘다. 하단 재생으로 움직임을 이어 볼 수 있고 원인 조사 화면의 현재 사실도 갱신된다. 담아 둔 과거 자료는 갱신하지 않는다.

동네 소식 → 다른 도시 문제 → **길을 막은 불법주차**를 선택하면 학교 앞·시장 옆·주거지 골목이 표시된다. 지도 표시를 누르면 그 현장으로 이동한다. 정책을 고르면 창을 접고 지도에서 적용 가능한 위치만 강조한다. 순찰은 세 현장, 잠깐 정차 공간은 학교·시장, 주차장은 빈 공터 중 한 곳을 누른다. 공터는 면적과 주차 가능 대수를 함께 보여 준다.

위치를 고르면 정책 창으로 돌아와 적용 예정 장소와 예산을 확인한다. **위치 변경**으로 다시 고를 수 있으며, 취소·Esc는 기존 계획을 유지한다. 선택하는 동안 시간은 멈추고 이전 재생 상태로 돌아간다. 지도 이름표는 서로 겹치거나 선택 가능한 땅을 가리지 않도록 옮기고 연결선으로 위치를 표시한다. 실제 땅 클릭과 이름표의 키보드 선택을 모두 지원한다. 도서관·공원 계획도 **지도에서 공터 선택**으로 같은 화면을 연다.

계획과 실제 시행한 위치는 구분한다. **선택한 정책 시행하기**를 눌러야 실제 도시에 반영되며, 시행 후에도 자료를 추가할 수 있다. 수첩은 결과 화면의 실험 기록 저장·관찰지 인쇄에 포함된다.

Mini Traffic City Simulator は、中央の 3D 都市ビュー、左側の編集ツールバー、右側の統計パネル、上部の実行コントロール、下部の操作ヒントで構成されています。

## 左側ツールバー

左側ツールバーは、都市マップを編集するための操作群です。現在選択中のモードは青色で表示されます。

### Road

道路配置モードです。グリッド上をクリックして道路の始点を決め、別のグリッド位置をクリックして終点を決めます。水平または垂直の直線道路が作成されます。

主な用途:

- 新しい道路を追加する
- 既存道路ネットワークに道路をつなげる
- 接続された地点を自動的に交差点として扱わせる

### Junction

交差点配置モードです。ボタンで選んだプリセットを、クリックしたグリッド位置に配置します。

使えるプリセット:

- `Cross`: 十字路を作成
- `T Road`: T 字路を作成

### Signal

信号配置モードです。交差点をクリックすると、その交差点に信号が追加または選択されます。信号は南北方向と東西方向を交互に制御します。

### Vehicle

車両追加モードです。道路ネットワーク上のノード付近をクリックすると車両を追加します。出発地や目的地を明示しない場合、アプリがランダムに経路を選びます。

`Add 8 Cars` を押すと、複数の車両をまとめて追加できます。混雑や信号制御の影響を観察したいときに使います。

### Select

選択/編集モードです。道路や交差点をクリックして選択します。選択中の道路は下部バーに車線数と方向が表示されます。

このモードではマウスドラッグでカメラを回転できます。

### Delete

削除モードです。道路をクリックすると削除します。右クリックでも近い道路を削除できます。

### One-way

一方通行切替モードです。道路をクリックすると、一方通行と双方向が切り替わります。一方通行道路には白い矢印が表示されます。

### Lane

新規道路、または選択中道路の車線数を `1` から `3` の範囲で変更します。車線数が増えると道路幅と車線ラインが変わります。

### Two-way / One-way

新しく作る道路のデフォルト方向を切り替えます。

### Reset City

サンプル都市マップを初期状態に戻します。既存の道路、信号、車両、統計状態はリセットされます。

## 右側統計パネル

右側パネルは、シミュレーションの状態確認と信号設定、混雑確認、統計比較に使います。

### Live Stats

リアルタイム統計を表示します。

- `Avg travel`: 到着済み車両の平均移動時間
- `Avg wait`: 到着済み車両の平均待ち時間
- `Throughput`: 目的地に到達した車両数
- `Jam length`: 混雑している道路の合計長
- `Avg speed`: 現在走行中車両の平均速度
- `Vehicles`: 現在の車両数
- `Stopped`: 停止中の車両数
- `FPS`: 描画フレームレート

### Signals

選択中、または代表信号の状態を表示します。

- `Green`: 青信号時間を変更
- `Yellow`: 黄信号時間を変更
- `Pattern`: 信号パターンを切替
- `Sync signals`: 全信号を同期または非同期に切替

信号状態は `ns-green`、`ns-yellow`、`ew-green`、`ew-yellow` のように表示されます。`ns` は南北方向、`ew` は東西方向を表します。

### Congested Roads

混雑度の高い道路を一覧表示します。`C` キーで混雑表示を ON にすると、道路色も混雑度に応じて変わります。

- 緑: 空いている
- 黄: やや混雑
- 赤: 渋滞

混雑度は車両密度、平均速度、停止台数をもとに算出しています。

### Save Stats

現在の統計値を比較用スナップショットとして保存します。信号周期や道路構成を変えたあと、現在値との差分を確認できます。

### Reset Compare

保存した統計スナップショットと比較表示をリセットします。

## 上部バー

- `Pause` / `Resume`: シミュレーションを一時停止または再開
- `Speed`: シミュレーション速度倍率を変更
- `Running` / `Paused`: 現在の実行状態

## 下部バー

現在の操作モード、選択中オブジェクト、次に行う操作のヒントを表示します。道路編集中やモード切替後は、ここを見ると現在のクリック操作の意味を確認できます。

## 推奨ワークフロー

1. `Road` で道路を追加する。
2. `Cross` または `T Road` で交差点を増やす。
3. `Signal` で交通量の多い交差点に信号を追加する。
4. `Vehicle` または `Add 8 Cars` で車両を増やす。
5. `C` で混雑表示を有効にする。
6. `Save Stats` で統計を保存する。
7. 信号周期や道路方向、車線数を変更する。
8. 右側パネルで改善/悪化を比較する。

## 다섯 도시 문제와 공통 조사 도구

물류는 왼쪽 **상품 재고**에서 네 상점의 실제 건물을 재고에 따라 녹색(15상자 이상)·노랑(5~15 미만)·주황(5 미만)·빨강(품절)으로 표시한다. 공급처의 대기 물량은 상점 재고와 구분한다. **물류 현황**의 화물차를 누르면 적재량·출처·목적지와 접힌 경로를 보고, 상점·공급처 목록은 필요할 때 펼친다. 실제 도착·하역 후에만 재고가 늘어난다. 추가 화물차 운영은 상단 동네 전체에, 지름길·하역 지원·외부 입구는 해당 위치에 표시한다. 결과는 전체와 상점별 못 산 양, 공장·이웃 마을 배송을 나누어 보여 준다.

동네 소식 → 다른 도시 문제 살펴보기에서 교통/쓰레기/공공시설/개발·환경/물류를 선택한다. 미완성 시나리오는 보이지 않는다. 주민 의견은 하단 도구에서 별도로 열며 다른 정보창을 닫는다. 사실·바라는 점을 구분하고 선택 이유를 적지 않아도 정책을 시행할 수 있다.

주민 의견을 열면 지도 위 해당 주택·학교·일터에 말풍선 표식이 나타난다. 교통 2곳, 수거 6곳, 시설 7곳, 환경 4곳, 물류 5곳이며 각 의견의 건물 ID로 실제 위치를 연결한다. 선택한 지역은 노란 테두리와 연결선으로 표시하고, 그 주민의 짧은 이야기 하나만 펼친다. ‘관찰한 사실과 자세한 의견’은 기본 접힘 상태이며 시행 후에는 같은 곳의 변화도 확인한다. 결과 창의 주민 의견과 저장 기록은 기존처럼 읽을 수 있다.

작은 화면에서는 번호 표식을 누르거나 위쪽의 이전·다음 버튼으로 차례로 듣는다. 선택한 주민의 이름과 장소는 열린 말풍선에 표시한다. 표식과 말풍선은 카메라 회전·확대에 맞춰 위치를 갱신하고, 서로 겹치는 경우 연결선을 유지하면서 빈자리로 옮긴다. 다른 도구를 열거나 Esc를 누르면 말풍선 지도를 닫는다. 지도 확인은 정책·수요·계산 결과를 바꾸지 않는다.

정책을 시행하면 해당 교차로·도로·시설·개발 부지에 청록색 ‘시행 중’ 표식과 적용 구역 테두리가 나타난다. 같은 시설이나 부지에 적용한 정책은 하나로 묶는다. 표식을 누르면 시행한 내용과 유의할 점을 읽는다. 전역 수거 운영 정책은 상단의 ‘동네 전체 · 시행 중’에 모은다. 개발 규모 축소는 도시 전체에 영향을 주는 규칙이 아니므로 ‘개발 부지 공통’으로 구분하며, 개발을 선택하지 않았다면 ‘변화 없음’을 함께 표시한다.

표시는 현재 실행 중인 시뮬레이션을 읽는다. 정책 체크나 건설 예정 부지만 바꿔서는 이전 시행 표시가 바뀌지 않으며, 시행·처음부터·시나리오 전환 때 갱신한다. 주민 의견을 함께 열면 지역 정책 표식은 작은 아이콘으로 줄어들며 여전히 눌러 읽을 수 있다. 정책 선택·동네 소식·통계 창을 읽는 동안 지역 표식은 잠시 접고 실제 적용 구역 테두리는 유지한다.

왼쪽 지도 도구는 시나리오에서 제공하는 자료만 표시한다. 혼잡도·쓰레기·시설 접근성·환경 부담·상품 재고·인구·시설 중 한 가지만 켜며 같은 버튼을 다시 누르면 일반 도시로 돌아간다. 통계 창의 ‘지도 자료’ 선택과 동기화한다. 선택한 자료의 범례만 펼치고 모바일에서는 도시를 가리지 않도록 아래쪽에 둔다.

쓰레기 보기는 수거 대상 6곳의 실제 건물 벽·지붕을 남은 양에 따라 흰색(0봉투)에서 진한 갈색(60봉투 이상)으로 연속적으로 바꾼다. 다른 건물은 원래 색을 유지한다. 실행마다 같은 기준을 사용하며 수거·새 발생에 따라 갱신한다. 잔량 숫자도 함께 표시한다. 수거차 목록에서 실제 차량을 선택하고 적재량·현재 목적지·접힌 방문 순서/경로를 확인한다. 자세한 지역 표는 필요할 때 펼친다.

시설 접근성은 도서관/공원을 고르면 주택 7곳을 예상 도보 시간으로 칠한다. 녹색 2분 이내, 노랑 2분 초과~4분, 주황 4분 초과~5분, 빨강 5분 초과 또는 연결된 길 없음이다. 보도와 횡단보도에 그린 청록색 테두리 길은 선택한 시설에서 5분 이내 닿는 보행 범위다. 횡단보도 대기와 출입로를 반영하고, 마지막 길은 시간 한계에서 끊는다. 범위의 띠 두께는 가독성을 위한 표시다. 건물 색은 거리·시간이고, 인원은 이용 가능/필요한 주민이다. 가까워도 자리가 모자랄 수 있다. 신설·출입로 정책을 시행하면 색과 범위를 갱신하고, 정원만 늘리는 확장은 범위를 바꾸지 않는다.

결과는 전체 수치와 지역별 차이를 나누며 불리해진 곳도 표시한다. 무단투기는 v6, 다른 사례는 v5로 저장하며 v3/v4/v5/v6을 읽는다. 인쇄는 이름·날짜·선택 정책·전후 표·근거·생각을 담은 브라우저 A4 관찰지다. 기록 열기는 현재 실험을 초기화하지 않는다.

시설 계획은 시간 조작 대신 계획 1회 비교를 쓴다. 시설 지도에서 도서관/공원과 접근성 레이어를 고르고, 접힌 동네 목록에서 경로를 살핀다. 정책 창의 4개 카드와 부지 선택은 기존 창 안에 표시한다. 지도 부지 미리보기에서 다시 정책으로 돌아갈 수 있다. 시행하면 시설이 생기거나 커지고, 결과에서 지역별 수혜와 주민회의를 필요할 때 펼친다. 예상 시간·계산된 이용 인원을 실제 보행 애니메이션이나 도착 수로 표기하지 않는다.

개발·환경은 5개 정책 카드와 지정된 두 부지를 쓴다. 개발 면적에 맞춰 건물·녹지가 바뀌고 추가 차량은 실제 도로에서 움직인다. 환경 자료의 지역·차량·부지·계산 방법은 기본 접힘 상태다. 지도는 현재 부담, 결과는 관찰 중 평균이며 ‘가상’ 표시와 숫자·범례를 함께 제공한다. 결과에서 기존 차량 140대의 도착과 개발로 추가된 수요/도착을 구분한다. 녹지는 전체 도시가 아닌 관리 부지 760㎡를 집계한다.
