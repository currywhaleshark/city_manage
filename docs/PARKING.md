# 공통 조사 수첩과 불법주차

2026-10-14 구현. 교과 연계의 근거와 후속 범위는 [지역 문제 계획](LOCAL_PROBLEMS_PLAN.md)을 따른다. 이번 범위는 공통 조사 흐름과 불법주차이며, 무단투기·수질오염은 후속 단계다.

## 수업 흐름

모든 시나리오의 하단 **우리 동네 조사** 또는 동네 소식의 **조사 시작**에서 연다. 현장 찾기 → 원인 조사 → 의견 듣기 → 해결책 결정 → 시행·비교 → 수정 제안을 한 단계씩 표시한다. 단계는 자유롭게 되돌아갈 수 있고 작성 여부로 정책 실험을 막지 않는다. 조사 중에는 시뮬레이션을 잠시 멈춘다. 현황을 계속 관찰하려면 하단 재생 버튼을 누른다.

- 장소별 관찰 사실과 가상 주민의 의견을 구분해 수첩에 담는다. 담은 시점·장소·전후 구분·문장을 복사하므로 시뮬레이션 진행이 이전 자료를 바꾸지 않는다.
- 학생이 원인에 대한 생각, 다른 방법의 장단점, 선택 이유를 적고 사용할 자료를 체크한다.
- 정책 시행 시 이유·대안 비교·사용한 자료 번호·정책을 별도로 보존한다. 다음 계획을 편집해도 이전 시행 근거는 바뀌지 않는다.
- 결과와 함께 다음 수정안·협력할 사람을 기록한다. JSON 저장, 다시 열기, 관찰지 인쇄에 조사 내용이 포함된다. 기록이 많으면 관찰지는 여러 쪽이 된다.
- 초기화·조건 변경·시나리오 전환은 새 수첩으로 시작한다. 문제를 바꾸기 전 필요한 결과를 저장한다.

## 불법주차 모형

정책 카드를 고르면 정책 창을 접고 지도에서 적용 가능한 곳만 강조한다. 순찰은 학교·시장·주거지 중 한 곳, 잠깐 정차 공간은 학교·시장 중 한 곳, 공동주차장은 비어 있는 공터 중 한 곳을 누른다. 공터 이름표에는 면적과 주차 가능 대수를 함께 표시한다. 강조한 땅과 이름표 모두 클릭할 수 있다.

위치를 고르면 정책 창에 적용 예정 장소와 남은 예산이 표시된다. **위치 변경**으로 다시 고를 수 있고 취소·Esc는 이전 계획을 유지한다. 위치 선택 중 시간은 멈추며 완료·취소 후 이전 재생 상태로 돌아간다. 장소를 고르는 것만으로 현재 시뮬레이션은 바뀌지 않고 **선택한 정책 시행하기**를 눌러야 적용된다. 도서관·공원 계획의 **지도에서 공터 선택**도 같은 선택 화면을 사용한다.

`ParkingSimulation`은 기존 교통 엔진과 같은 도로·신호·보행 수요를 사용한다. 같은 시드의 일반 차량 140대와 보행자 60명을 유지하고, 초기 주차 수요 6대를 별도 계산한다. 주차 수요의 시간 변화에 별도 무작위 스트림을 써서 배경 교통을 바꾸지 않는다.

학교 앞·시장 옆·주거지 골목에 각각 차도 1대와 보행로 1대가 있다. 학교는 짧은 정차, 시장은 하역과 장시간 주차, 주거지는 장시간 주차를 나타낸다. 모두 학습용 가상 수요이며 실제 단속 기준이나 지역 통계가 아니다.

- 차도 차량은 실제 차로의 서비스 차량으로 등록해 정지한다. 뒤차의 추종·대기·교차로 흐름에 영향을 준다. 정차가 끝나면 도로를 따라 외부 출구로 나간다. 일반 차량의 도착 수에 섞지 않는다.
- 보행로 차량이 남아 있으면 새 보행자는 차 바깥쪽으로 3m 돌아 나갔다 합류하는 경로를 사용한다. 경로는 6m 길어지고, 합류할 때 같은 보행 방향의 순서를 지킨다. 이미 우회 중인 사람은 차량이 떠나도 갑자기 원래 길로 순간 이동하지 않는다.
- 보행자 우회 인원과 실제로 더 걸은 거리를 집계한다. 신호 대기와 우회 거리는 별개다.

| 정책 | 예산 | 위치·효과 | 고려할 점 |
|---|---:|---|---|
| 순찰 구역 지정 | 30 | 선택한 현장 1곳의 차도 차량은 40초, 보행로 차량은 48초에 정차를 끝낸다 | 다른 현장에는 적용되지 않고 주차 자리도 생기지 않는다 |
| 공동주차장 만들기 | 55 | 선택한 공터를 사용. 최소 400㎡, 용량은 공터 면적÷240의 정수 부분 | 가까운 수요만 이용. 해당 공터의 도서관·공원 기회와 경쟁 |
| 잠깐 정차 공간 | 25 | 학교 또는 시장의 길 밖 공간 1면. 150초 이내 수요 1대 | 장시간 주차를 받아들이지 못한다 |

공동주차장은 목적지까지의 블록 직각 거리를 예상 보행 거리로 사용한다. 짧은 정차는 115m, 긴 주차는 185m까지 이용한다. 실제 보행 경로·교량 접근 시간의 계산은 아니다. 주차 뒤 예상 거리 합계와 보행자가 불법주차 때문에 실제로 더 걸은 거리 합계를 구분해 표시한다.

공통 `city/parcels.ts`가 시설과 주차장의 부지 중복·면적을 검사한다. 주차 계획은 예약된 다른 시설 부지와 충돌하면 거부한다. 현재 개별 시나리오는 독립 실험이므로 시설 시나리오의 이전 건설이 다음 주차 시나리오로 누적되지는 않는다. 여러 문제 사이의 영구적인 공터 공유는 종합 문제 단계의 범위다.

## 비교·기록

동일한 시드·관찰 시간·일반 교통·보행·주차 수요만 비교한다. 불법주차 점유 시간 합계, 우회 인원·거리, 정해진 자리 이용, 일반 차량 도착, 주차 뒤 예상 보행 거리, 예산을 함께 표시하고 현장별 차이도 제공한다. 정책 조합에 임의의 감점·만족도·승인율을 부여하지 않는다.

기록 버전은 5다. 3·4번 기록도 읽기 전용으로 계속 연다. 주차 수량·시간·현장 합계·비용·부지·수요와 조사 자료 번호를 검사하고, 저장된 학생 입력은 HTML로 실행하지 않는다. 주차 모델은 `parking-v1`, 교통은 `city-traffic-v5`를 사용한다.

## 이번 버전의 단순화

처음 주차한 6대만 다룬다. 새로운 주차 수요의 반복 발생·단속 뒤 다른 골목으로 이동·재주차는 없다. 공동주차장과 정차 공간의 배정은 시작 때 한 번 결정하고 빈자리를 재배정하지 않는다. 보행로·주차면 차량은 이용 시간이 끝나면 표시가 사라진다. 이 차량들의 진입·후진 운전은 생략한다. 도로 위 불법주차 차량의 출구까지 운전은 실제 교통으로 계산한다. 주차장 사용자의 도보는 예상 거리만 비교하고 별도 주민을 추가 생성하지 않는다.

수질, 불법 투기, 사고 확률·건강 피해·과태료 체계는 이번 모형에 포함되지 않는다.
