# 사회과 확장 — Phase 0·1

## 외부 출입·강 건너 출퇴근 보완 · river-districts-v3 (2026-10-14)

동서 외부 도로 4곳은 도시 바닥의 정확한 경계(x=-138/330m)까지 이어진다. 일반 차량은 경계에서 생성되며, 외부로 나가는 차량은 경계에 도착하면 운행을 마치고 제거된다. 경계에는 신호등·교차로 바닥을 그리지 않는다. 화물차의 외부 하역·복귀 경로는 계속 계산하되 경계 밖 도로와 차량은 화면에 표시하지 않는다.

기존 지도 확장은 출퇴근 목적지를 옛 지도에 남겨 두고 있었다. `city-traffic-v5`에서는 서쪽 주거지와 강 건너 상업·산업지구를 실제 출발지·목적지로 사용한다. 기본 140대는 등교 70대, 출근 42대, 귀가 28대다. 이 중 내부 출퇴근 42대는 강을 건너며, 외부 유입 14대·유출 14대도 포함한다. 출발 예정 시간·목표 속도는 같은 시드에서 재현되며 정책 전후 같은 수요를 공유한다. 목적지 변경으로 과거 v4와 정책별 결과 수치는 달라진다.

다리 3곳의 양쪽 강둑은 도로 폭보다 넓은 12m 구간을 비워 교량 위를 가로지르지 않는다. 경계 진입·도착 좌표, 실제 다리 통과·전량 도착, 렌더링된 도로 끝과 강둑 틈을 회귀 검사한다. 기존 v4의 45개 관측 비교는 당시 수요를 별도 테스트 fixture로 보존해 엔진 회귀만 확인한다.

## 도시 면적 확장 (2026-10-14)

도시 바닥을 234×234m에서 468×468m로 확장했다(가로·세로 2배, 면적 4배). 기존 등굣길을 남기고 동쪽·남쪽 도로를 연결했다. 도시 교차점 81개와 외부 연결점 8개(경계 4·외부 4), 하천을 건너는 다리 3개가 차량 경로망을 구성한다. 주거지구는 서쪽, 상업지구는 중앙과 강 건너 북쪽, 산업지구는 강 건너 남쪽에 배치했다.

새봄천에는 상류·하류 방향을 표시했다. 현재는 하천 지형과 교량이며 수질·오염물질의 하류 이동은 계산하지 않는다. 기존 환경 부담은 공장·자원순환센터·도로의 거리 영향을 합산한 교육용 지표다. 공장과 완충 녹지를 산업지구로 옮겼으며, 인근 산업 블록도 관찰 지점에 포함한다.

자원순환센터는 산업지구에 상시 표시되는 별도 시설이다. 수거차가 이곳에서 출발하고 실제 도로와 다리를 거쳐 돌아와 하역한다. 외부 물류 공급처는 지도 경계 밖의 강빛마을·들녘마을에 있으며 출입·하역·복귀 도로가 연결된다. 교통 시나리오의 차량 140대와 보행자 60명은 유지하고 차량 목적지는 확장 지구에 맞췄다. 추가 주택의 인구는 시설 접근성 계산에 포함한다(12개 주거 블록, 1,180명).

### 공터를 먼저 고르는 시설 계획

- A~F의 6개 공터를 지도에서 확인한다. 기존 건물·하천과 겹치지 않는 빈 부지다.
- 도서관: 예산 55, 최소 400㎡. 공원: 예산 35, 최소 900㎡. 한 공터에는 하나만 건설한다.
- B(484㎡), E(676㎡)는 공원 면적이 부족하다. A(900㎡), C·D·F(각 1,156㎡)는 둘 중 하나를 선택할 수 있다.
- 여러 공터에 시설을 함께 계획할 수 있으나 총예산 100을 넘을 수 없다. 같은 시설을 여러 곳에 지어도 각각 비용을 센다. 기존 도서관 확장 35·출입로 개방 20도 같은 예산에서 차감한다.
- 결과는 이용 가능 주민, 실제 배치 위치, 사용한 공터·면적, 남은 공터·예산을 제공한다. 다음 계획 편집이 이미 시행한 지도 표시에 영향을 주지 않는다.
- 기록 JSON은 시행한 시설별 부지를 저장한다. 이전 단일 부지 기록도 읽을 수 있고, 새 기록의 부지 중복·면적·예산을 검사한다.
- 보행 경로의 출발점별 계산을 재사용하고 신호등 전구를 인스턴스로 합쳐 확장에 따른 부담을 줄였다.

쓰레기·시설·환경·물류 모델 버전은 v2다. 아래 내용과 다른 문서의 v1 결과·성능 수치는 이전 지도에서 측정한 역사 기록이다.

## 수거 규칙

- 같은 시드에서 초기 쓰레기·발생률·참여율과 일반 교통 수요가 같다. 수거용 난수는 교통과 독립된 스트림이다.
- 6개 수거장, 기본 2대, 차량당 55봉투. 봉투·인구·수요는 교육용 가상 단위와 설정이다.
- 수거차도 차로·신호·보행자 횡단 점유·교차로 출구 예약·앞차 대기의 영향을 받는다. 도로 위 정차 차량이므로 뒤차를 지연시킬 수 있다.
- 지정된 차로의 정차 위치에 실제 도착해 정지한 뒤 초당 0.9봉투를 싣는다. 도착 전에는 수거하지 않는다. 초기 쓰레기 + 발생량 = 잔량 + 수거량, 수거량 = 차 안 적재량 + 처리시설 하역량을 보존한다.
- 적재량이 차면 처리시설로 돌아가 18초간 하역한다. 수거 중 다 못 비운 곳은 하역 후 다시 방문한다. 배정된 순서를 모두 마치면 마지막 하역 뒤 운행을 종료한다.
- 한 아침의 유한한 방문 일정이다. 비운 곳에서 새로 생긴 쓰레기를 다시 순회하는 일일 운영 모델은 아직 없다.
- 기본 순서: 학교 → 상점가 → 북쪽 → 학교 가는 길 → 서쪽 끝 → 남쪽. 순서 정책: 남쪽 → 서쪽 끝 → 학교 가는 길 → 북쪽 → 상점가 → 학교. 차량별로 순서를 나누어 맡는다.
- 평균 이동시간은 **도착한 수거 구간만** 집계하며 출발 대기·신호 대기·정체를 포함한다. 수거·하역 중 정차 시간은 제외한다. 미완료 이동 구간 수를 결과 상세에 함께 표시한다.
- ‘한 차례 수거를 마친 곳’은 한 번 모두 비운 곳이다. 이후 새 쓰레기가 생겨도 완료 이력을 지우지 않는다. 현재 잔량 및 현재 1봉투 미만인 곳은 별도 값이다.

| 정책                   | 비용 | 실제 변경                                               |
| ---------------------- | ---: | ------------------------------------------------------- |
| 쓰레기차 추가 투입     |   45 | 2대 → 3대, 방문 임무를 재분배                           |
| 수거 순서 조정         |   20 | 외곽·남쪽을 우선 방문. 실제 경로와 구간 이동시간 변경   |
| 분리배출·쓰레기 줄이기 |   35 | 향후 발생량 × (1 − 0.6 × 지역 참여율). 초기 적치량 유지 |

참여율은 지역별 25~75%로 고정한 가상 조건이다. 정책이 수거율이나 주민 만족도를 직접 더하지 않는다. 전체 평균이 좋아도 나빠진 수거장을 별도로 표시하고, 주민 의견에도 그 지역의 변화가 나타난다. 일반 차량의 도착 수에서도 운행 부담을 확인할 수 있다.

## 조사·기록·수업

지도는 일반/교통 혼잡/인구·시설과 수거 시나리오의 쓰레기 잔량을 지원한다. 수거 지도에는 색과 함께 지역명·수치를 표시한다. 건물·수거장·수거차를 선택하면 상세를 보고, 수거차 경로는 접힌 상세에서 확인한다. 주민 의견은 관찰 사실과 개인의 바라는 점을 구분하며 단일 만족도 점수로 합산하지 않는다.

정책 선택 이유와 결과 성찰은 선택 입력이다. 장소·통계·주민 의견·지도에서 조사한 시각과 당시 수치를 최대 60건 기록한다. JSON `schemaVersion: 4`는 기존 교통 필드를 유지하면서 시나리오 ID, 공통 summary, 수거 전후 통계, 차량 임무·수거 이벤트, 선택 정책, 주민 의견, 조사 자료와 근거를 추가한다. 모델은 교통 `pedestrians-v4`, 수거 `waste-services-v1`로 구별한다.

동네 소식 → 저장한 기록 열기는 v3 교통 기록과 v4 기록을 읽기 전용으로 연다. 현재 실험을 재생·덮어쓰기 하지 않는다. 파일 크기·버전·관찰 시간·수치·필수 수거장 데이터를 검사하고 입력 글은 HTML로 실행하지 않는다. 결과와 저장 기록에서 브라우저 인쇄로 전후 표·선택 정책·근거·성찰을 출력한다. 기본 수거 관찰지는 A4 1쪽으로 검사했다.

## 후속 범위와 한계

- Phase 2 공공시설 접근성·주민회의는 후속 작업으로 완료했다. Phase 3 환경·개발도 별도 단계로 완료했다. Phase 4 물류·경제, Phase 5 지역 홍보·방문객, 자유 운영·교사 정책 제한은 남아 있다. 미완성 메뉴나 가짜 수치를 노출하지 않는다.
- 쓰레기차는 기존 차량의 3.8m × 1.8m 충돌 크기를 공유하는 소형 모델이다. 대형 트럭 회전반경·별도 정차 차로·작업자 보행·후진 진입·차종별 배출량은 미구현이다. 처리장 옆 지정 도로에서 하역한 뒤 운행 종료 차량을 제거한다.
- 혼잡하면 정해진 5·10·15분 안에 임무를 끝내지 못할 수 있다. 막힌 도로를 순간이동하거나 결과를 보정하지 않는다. 정체 회피를 위한 실시간 서비스 재경로 탐색은 없다.
- 악취·소음·건강 영향을 잔량으로 직접 환산하지 않는다. 주민의 불편 호소는 가상 의견이며 실제 환경영향평가가 아니다.
- 보행자는 기존 네 경로를 유지한다. 가상 전체 인구가 실제로 걸어 다닌다고 표현하지 않는다. 인구·시설 숫자는 실측 자료가 아니다.
- 학교 PC·학생 수업 실측은 미실시. CPU 감속 성능 검사는 실제 학교 하드웨어를 대신하지 않는다.

검증 명령과 증거 파일은 `VERIFICATION.md`, 성능 조건은 `PERFORMANCE.md`를 참고한다.
