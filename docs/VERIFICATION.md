### 보행 안전과 결정성

- 7분에서 세 정책 조합의 도착 증가: +19, +25, -1대. 세 번째 아침은 전체 1대당 대기도 209.9초에서 210.2초로 증가했다.
- 첫 번째 아침의 조합은 7분에 60대가 도착해 기본 41대보다 많지만 신호 단독 79대보다 적다. 세 번째 아침의 조합은 3분 -1대, 7분 -1대, 10분 +36대였다. 관찰 시간과 수요에 따라 상대 효과가 달라진다.
- 7분의 실제 차로 변경 횟수는 일방통행 단독에서 1·3·1회, 세 정책 조합에서 1·7·2회였다. 짧은 도로의 사전 차로 선택과 안전 조건 때문에 횟수는 적다. 발생 횟수를 늘리기 위한 임의 변경은 넣지 않았다.

별도 합성 조건에서는 양쪽에 각 12대가 출발하고 동서 초록불을 계속 유지했다. 중앙 교차로 양방향 동시 점유는 총 23.9초, 방향별 평균 진입 간격은 3.20초, 24대의 전체 이동 완료는 51.3초였다. 이는 이 모델의 배출 동작 측정이며 실제 도로의 포화교통량을 재현했다고 주장하는 자료는 아니다.

## 정차 행렬의 연속 통과와 용량 비교

`junction-platoons-v3`에서 추가한 네 가지 회귀 검사는 직진·좌회전의 교차로 내 추종과 차체 비중첩, 막힌 출구의 저장 공간 및 재개통 후 전량 배출, 노란불에서 미진입 예약만 취소하는 동작이다. 동일 경로 차량이 동시에 교차로 안에 있으며 중심 간 5.3m 이상을 유지한다. 출구 예약 집합의 소유권과 최종 해제도 확인했다.

별도의 256m 접근 차로에서 30대가 빨간불에 완전히 정차하도록 엔진을 실행한 후 243초에 초록불로 바꿨다. 네 번째 차량 통과 이후의 26개 연속 진입 간격을 측정했다. 직진 평균은 2.2308초로 약 1,614대/시간/차로, 좌회전은 2.60초로 약 1,385대/시간/차로에 해당한다. 둘 다 최대 두 대가 같은 경로의 교차로 안에서 동시에 주행했고 30대 모두 도착했다. 시간당 값은 지속 초록불에서의 환산값이며 실제 신호 주기의 처리량과 다르다.

[FHWA의 2008년 보존판 신호 운영 매뉴얼 3.3.2절](https://ops.fhwa.dot.gov/publications/fhwahop08024/chapter3.htm)의 일반적인 관측 범위 1,500~2,000대/시간/차로와 직진 값을 비교했다. 현재 운전자 매개변수를 유지한 결과이며 특정 학교 앞 도로의 실측 보정은 아니다. 출발 반응시간은 명시적으로 모델링하지 않으므로 첫 차량의 출발 손실시간을 재현한다고 주장하지 않는다. 좌회전은 낮은 곡선 목표속도를 적용한 별도 측정이다.

출구 34m를 빨간불로 막으면 공간에 맞는 6대까지만 통과하고 나머지 24대는 교차로 밖에 남는다. 진입 허가 차량도 모두 출구로 빠져나와 교차로 안에 정체된 차량이 없었다. 출구를 열면 30대 전부 도착했다. 막힌 조건의 짧은 통과 간격은 포화교통량으로 환산하지 않는다.

오디오: 3초, 44.1kHz, 16-bit 스테레오 PCM, 피크 0.2554, RMS 0.0463, 비정상 표본 0. 직접 청취 평가는 미실시.

## 재현 자료

- `output/verification.json`: 정책별 전체 통계, 엔진 실행 시간, 배출 완료 시각, WAV 검사.
- `output/experiments.json`: 45개 관측값의 전체·집단·동일 차량 분석과 합성 교차로 배출 결과.
- `output/capacity.json`: 실제 정차 30대 배출 간격, 진입 속도, 동시 통과 수, 비교 문헌과 조건.
- `output/performance.json`: 수요·품질·CPU 감속별 프레임과 처리 시간, 실제 동시 차량 수와 GPU 정보.
- `output/production.json`: 배포 청크 경로, 로딩 실패 복구, 정책 결과와 오류 기록.
- `output/browser-metrics.json`: UI에서 실행한 전후 통계와 콘솔 오류 결과.
- `output/playwright/city-overview.png`: 기본 도시와 실제 대기 행렬.
- `output/playwright/city-lane-change.png`: 실제 주행 중 차로 변경을 관찰한 화면.
- `output/playwright/policy-results.png`: 세 정책 조합 비교 창.
- `output/playwright/results-impact.png`, `results-matched.png`, `results-mobile.png`: 접어서 보는 분석 및 모바일 결과.
- `output/playwright/layout-*.png`: 반응형 스크린샷.
- `npm run verify:report`: 결과 JSON 재생성. 측정 시간은 실행마다 달라질 수 있다.
- `npm run verify:experiments`: 반복 조건·배출 결과 JSON 재생성.
- `npm run verify:capacity`: 정차 행렬 용량 비교 JSON 재생성.

스크린샷은 로컬 검증 산출물로 `.gitignore`에 포함된다. 논리 테스트와 비교 결과에는 브라우저가 필요 없다. 브라우저 검증은 Chrome 설치가 필요하며 실행 시 Playwright가 로컬 개발 서버를 시작하거나 기존 5174 포트를 재사용한다.
