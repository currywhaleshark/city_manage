# 4학년 2학기 사회 — 우리 지역 문제 탐구 확장안

> 2026-10-14: 공통 조사·불법주차·무단투기·독립 수질오염을 구현했다. 현재 규칙은 [PARKING.md](PARKING.md), [DUMPING.md](DUMPING.md), [WATER.md](WATER.md)를 참고한다. 무단투기는 기존 수거 엔진의 확장 사례이고 수질은 별도 물질 이동 모형이다. 두 사례는 5분씩 3차 연속 관찰을 사용한다. 상태를 공유하는 종합 문제는 후속 계획이다.

작성: 2026-10-14. 상태: 조사에 근거한 개발 제안이며 구현 현황은 위에 별도 기록한다. 사용 교과서 출판사는 미정이고, 사용자가 공통 교육과정 기준 진행을 선택했다. 이 문서는 특정 교과서의 모든 예시를 재현하는 요구서가 아니다.

## 2. 학습 목표와 공통 플레이 흐름

학습 목표는 문제의 위치와 원인을 자료로 설명하고, 서로 다른 주민의 입장을 고려해 예산·공간 안에서 해결책을 선택한 뒤 결과를 다시 판단하는 것이다.

**현장 찾기 → 원인 조사 → 의견 나누기 → 해결책 결정 → 시행·비교 → 수정 제안**

1. 현장 찾기: 지도에 2~3개의 짧은 주민 말풍선만 표시한다. 하나를 누르면 그 장소로 이동하고 문제를 관찰한다.
2. 원인 조사: 장소·시각이 붙은 자료를 수집한다. 예: 주차면 수와 이용 수, 수거 일정, 상류·하류 관찰값. 기존 조사 기록 기능을 확장해 자료가 생성된 당시 값을 보존한다.
3. 의견 나누기: 학생·상인·주민·작업자 등 3개 정도의 입장을 순서대로 본다. 관측 사실과 주민이 원하는 것을 구분한다. 불편을 호소한다는 이유만으로 주민을 이기적인 인물로 처리하지 않는다.
4. 해결책 결정: 한 번에 정책 3개 안팎을 비교한다. 해결하려는 원인, 적용 위치, 비용·필요 공간, 남을 수 있는 불편을 함께 본다. 처음 화면에는 짧은 설명을, 자세한 계산은 펼침 영역에 둔다.
5. 시행·비교: 같은 조건의 시행 전·후 지도를 전환한다. 핵심 수치 3개와 좋아진 곳·불편이 남은 곳을 보여준다.
6. 수정 제안: 선택 근거, 다른 주민의 의견, 결과를 보고 바꿀 점을 기록한다. 기존 JSON 저장·관찰지 인쇄에 포함한다.

수업용 안내에서는 자료 2개와 다른 입장의 주민 의견을 참고하도록 유도한다. 임의의 점수·찬성률로 답안을 자동 채점하거나 글을 길게 써야만 시뮬레이션을 진행하도록 제한하지 않는다. 교사는 문제 파악·근거 연결·다른 입장 고려·결과에 따른 수정의 네 관점으로 기록을 검토할 수 있다.

## 3. 불법주차 — 학교 앞과 시장 골목이 막혀요

### 현장과 원인

학교 앞 승하차 차량, 시장의 장시간 주차, 주거지의 주차 공간 부족을 소수의 지점에 배치한다. 한 지점에서 모든 원인이 발생하게 하지 않고 지도 자료로 차이를 찾게 한다. 차량이 실제 차로 또는 보도 일부를 점유하며, 점유 시간과 막힌 구간을 표시한다.

### 정책 후보

| 정책 | 바꾸는 조건 | 함께 고려할 점 |
| --- | --- | --- |
| 순찰·단속 구역 지정 | 지정 지점에서 불법 점유를 발견하고 해소하기까지의 시간 | 인력·운영비, 다른 골목으로 옮겨 가는지 조사 |
| 공터에 공동주차장 조성 | 정해진 주차면 수와 목적지까지의 보행 거리 | 예산과 공터 사용, 같은 땅의 도서관·공원 포기 |
| 승하차·물건 내리는 공간과 시간 정하기 | 짧은 정차 수요를 허용 장소·시간으로 배분 | 목적지와의 거리, 이용 가능 시간, 수용 대수 |

평가는 불법 점유 대수·시간, 막힌 보행 구간·추가 보행 거리, 차량 대기시간으로 한다. 과태료 수입을 성공 점수로 삼지 않는다. 단속 후 다른 곳으로 이동하는 결과도 실제 대체 주차 선택이 발생할 때만 표시한다.

### 구현 범위

- 기존 정차 차량·추종·충돌 엔진을 재사용하되 점유 객체와 주차 수요·합법 주차면을 별도 관리한다.
- 1차에는 미리 정한 3곳과 유한한 주차 시간, 1곳의 대체 공터로 범위를 좁힌다. 막힌 차로에서 차량이 장애물을 통과하지 않도록 한다.
- 보행자는 현재 네 고정 경로만 움직이므로 우회 경로·통행 가능 폭을 별도 구현해야 한다. 1차는 영향 지점의 짧은 대체 보행 경로만 추가한다.
- 같은 방향으로 안전하게 지나갈 수 없는 구간에서는 기다리게 한다. 반대 차로를 이용한 추월은 후속으로 둔다.
- 공터 소유·사용 정보는 기존 시설 계획과 공유한다. 한 공터에 주차장과 도서관을 겹쳐 건설할 수 없다.

## 4. 쓰레기 무단투기 — 치웠는데 또 쌓여요

### 현장과 원인

기존 수거장의 정상 배출·수거 지연과 골목·공터·하천변의 무단투기를 구분한다. 정상 배출 장소가 멀거나 안내가 부족한 조건과, 편의를 위해 지정 장소를 이용하지 않는 조건을 조사 자료에 담는다. 규칙을 지킨 주민의 쓰레기가 미수거되었다고 무단투기로 판정하지 않는다.

### 정책 후보

| 정책 | 바꾸는 조건 | 함께 고려할 점 |
| --- | --- | --- |
| 청소·수거 인력 배치 | 기존 투기물을 실제 방문해 치우는 속도와 순서 | 재발 원인이 남으면 다시 쌓임, 다른 곳의 수거 지연 |
| 지정 배출 장소 설치·수거 일정 개선 | 배출 장소까지 거리·보관 용량·넘침 발생 | 설치 공간과 수거 업무, 가까운 주민의 불편 |
| 배출 안내·주민 활동·집중 순찰 | 규칙을 알고 따르는 비율과 현장 관리 범위 | 효과가 나타나는 시점과 참여 범위, 지속 관리 비용 |

평가는 남은 투기량, 새 투기·재발량, 지정 장소의 넘침과 수거 부담으로 한다. 건물의 기존 흰색→갈색 수거 지도를 유지하면서 투기 지점에는 별도의 봉투 모형과 표식을 둔다. 선택한 지점에서 양과 발생 기록을 읽는다.

### 구현 범위

- `정상 배출`, `지정 장소 넘침`, `무단투기`에 각각 발생·위치·수거 기록을 둔다. 전체 쓰레기량도 합산해 한 곳의 감소가 다른 곳으로 옮겨간 것인지 확인한다.
- 수거차가 도착해 실제 작업한 만큼만 줄어든다. 일반 수거차의 임무에 투기 지점 방문을 추가하되 기존 수거장 일정과 경쟁하게 한다.
- 하루의 발생→청소→재발을 비교하는 관찰 회차를 도입한다. 화면의 분 단위 운행과 다음 관찰일을 구분하고 정책 시행 몇 초 만에 주민 전체 행동이 바뀌지 않게 한다.
- 같은 시드의 기본 배출 수요·행동 선택용 난수는 정책 전후 공유한다. 정책은 배출 위치 선택·참여·수거 조건에 작용하고 유리한 새 난수를 뽑지 않는다.
- 안내·참여 효과는 교육용 가정으로 표시하고, 실제 정책 효과로 해석하지 않는다. 구체적인 비용과 비율은 비교 실험 후 정한다.

## 5. 수질오염 — 강 아래쪽 물은 왜 더러울까요

### 현장과 원인

새봄천을 여러 흐름 구간으로 나누고 상류·배출구 아래·하류에 관찰 지점을 둔다. 산업지구의 배출구, 생활하수 유입구, 하천변 쓰레기를 구분한다. 시나리오의 공장만을 일괄적으로 오염 원인으로 취급하지 않고 어떤 유입이 실제로 발생했는지 자료로 확인하게 한다.

### 정책 후보

| 정책 | 바꾸는 조건 | 함께 고려할 점 |
| --- | --- | --- |
| 배출구 처리 시설 개선 | 해당 유입구에서 강으로 들어가는 오염 부하 | 설치·운영 비용, 다른 유입구에는 직접 효과가 없음 |
| 하수관·하수 처리 개선 | 생활하수의 유입·처리량 | 공사 범위·예산·시설 공간, 효과가 하류에 도달하는 시간 |
| 하천변 청소·유입 차단 | 육상 투기물과 물 위에 떠 있는 쓰레기의 양 | 물에 섞여 흐르는 오염 성분은 별도로 처리해야 함 |

평가는 지점별 가상 오염도, 하류로 이동한 오염량, 새 유입량·처리량으로 한다. 하천 색과 흐름 화살표, 관찰 지점의 수치를 함께 보여준다. 색은 교육용 표시이며 실제 하천은 눈에 보이는 색만으로 수질을 판단할 수 있다는 식으로 설명하지 않는다.

### 구현 범위

- 첫 버전은 고정 유량·일정 방향의 단순 구간 모델로 한다. 유입→구간 이동→처리→지도 밖 유출의 양을 기록한다. 지형과 물의 흐름 방향은 같은 정의를 사용한다.
- 오염원 차단 후에도 이미 하류로 이동한 오염은 즉시 사라지지 않는다. 전·후 비교는 같은 유량·기본 유입 일정·관찰 시간에서 수행한다.
- 물 위 쓰레기와 물에 섞인 오염 부하를 분리한다. 청소 정책이 두 값을 모두 일괄 감소시키지 않는다.
- `낮음·보통·높음`과 가상 단위를 사용한다. 실제 수질 등급·음용 가능·어류 폐사·건강 피해를 현재 가상 수치로 산출하지 않는다.
- 공터 설치형 처리 시설과 기존 배출구 개선형 정책을 구분한다. 기존 자원순환센터가 자동으로 하수도 처리하는 시설이 되지 않게 한다.
- 비·유출·무단투기의 하천 이동 연계는 세 개별 문제 구현 후 추가한다. 처음부터 강우·침수·수질 화학을 함께 구현하지 않는다.

| 순서 | 산출물 | 완료 조건 |
| --- | --- | --- |
| 1 | 공통 탐구 흐름 + 불법주차 사례 | 현장 자료→주민 의견→정책→결과→수정 기록 한 사이클 완성. 실제 차량·보행 통행 영향과 주차면·공터 중복 방지 검증 |
| 2 | 기존 쓰레기 시나리오의 무단투기 사례 | 정상 배출과 투기 구분. 수거 후 재발, 지점 이동, 전체 수량 보존과 기존 수거 지연 검증 |
| 3 | 독립 수질오염 사례 | 상류·하류 차이, 전파 지연, 오염원별 처리 범위, 지도 밖 유출을 포함한 양의 보존 검증 |
| 4 | 선택형 종합 문제 | 주차로 인한 수거 지연, 하천변 쓰레기 유입 등 이미 구현한 원인만 연결. 예산·공터·운영 인력을 공유하고 기존 개별 사례 유지 |

첫 화면에서는 한 문제만 선택하고 해당 지도와 주민만 보여준다. 지역 홍보·물류 등 기존 사례는 다른 문제 목록에 유지한다. 종합 문제는 교사나 학생이 별도로 선택했을 때만 여러 영향을 함께 드러낸다.

검증은 전후 동일 조건, 물량·차량 보존, 정책 적용 위치와 영향 범위, 통행 시 충돌·관통 없음, 저장 당시 근거 보존을 우선한다. 전체 평균이 개선되어도 악화된 장소를 숨기지 않는다. 추가 정책의 역효과는 공간·용량·동선의 실제 경쟁에서 발생하게 하고 조합에 임의의 감점 계수를 넣지 않는다.

## 7. 기존 코드와 연결 지점

- `src/scenarios/index.ts`: 사례 등록, 중심 성취기준, 지도 종류와 관찰 지표. 불법주차와 수질은 별도 사례, 무단투기는 기존 수거의 확장 사례로 제안한다.
- `src/simulation.ts`, `src/simulation/services/waste.ts`: 실제 길 점유·방문·정차·수거 재사용. 가상 만족도를 더하는 것으로 물리적 결과를 대신하지 않는다.
- `src/simulation/pedestrians.ts`: 불법주차 영향 구간의 보행 우회 추가가 필요하다.
- `src/city/world.ts`, 시설 계획: 공터 점유와 지도 좌표 공유. 프로젝트 전체의 공통 부지 계획 모델로 확장해야 한다.
- 신규 수질 모듈: 기존 거리 기반 환경 부담과 분리해 계산한다. 환경 개발 정책과의 연계는 독립 모델 검증 후 추가한다.
- 기존 주민 지도·정책 위치·조사 기록·전후 결과·인쇄: 공통 탐구 흐름의 기반으로 재사용한다.
- 기록 버전: 새로운 현장 자료, 대안 비교, 선택 이유와 결과 수정 의견을 저장하도록 갱신하고 이전 실험은 읽기 전용으로 계속 열 수 있게 한다.

정책별 세부 비용·효과 비율·관찰일 수는 다음 구현 단계의 실험으로 결정한다. 현재 확정 제안은 세 가지 문제의 인과 구조, 단계별 노출, 근거 중심 의사결정, 위의 개발 순서다.
