# 쓰레기 무단투기 조사

2026-10-14 구현. **동네 소식 → 다른 도시 문제 → 치웠는데 또 쌓이는 쓰레기**에서 연다. 기존 수거 모형 위에 별도 사례를 추가하고 공통 조사 수첩의 여섯 단계를 사용한다.

## 현장과 관찰

주택가 뒷골목·공터 옆 길·새봄천 산책길에 봉투와 이름표를 표시한다. 현장에서는 남은 투기·새 투기·청소 뒤 재발·배출 장소의 가상 거리·최근 배출 기록을 읽는다. 주민 세 명의 사실과 의견을 지도 말풍선과 수첩에서 확인한다.

정상 배출한 여섯 수거장은 기존 건물의 흰색→갈색 지도와 수거통으로 표시한다. 용량 초과는 **정상 배출의 넘침**이며 무단투기로 바꾸지 않는다. 새 배출함은 녹색이고 넘친 봉투를 주변에 그린다. 봉투 모형은 축약 표현이며 이름표의 숫자가 실제 계산값이다.

5분씩 세 번, 총 900초를 연속 관찰한다. 각 경계에서 일시정지해 자료를 담고 재생으로 이어 간다. 현황의 **관찰 지점까지 빠르게 보기**는 다음 300·600·900초까지, 하단 **끝까지**는 남은 관찰 전체를 계산한다. 실제 날짜가 바뀌는 모형은 아니며 차량과 수거 업무도 회차 사이에 이어진다.

## 정책

| 정책 | 비용 | 바꾸는 조건 | 함께 볼 점 |
| --- | ---: | --- | --- |
| 현장 먼저 청소 | 35 | 선택한 투기 현장을 방문 순서 맨 앞에 넣음 | 두 차가 방문을 나누므로 기존 담당·순서가 바뀔 수 있음. 배출 원인은 남아 재발 가능 |
| 지정 배출 장소 | 45 | 현장 옆 12㎡에 16봉투 배출함과 수거 방문 추가 | 방법을 모르는 주민은 그대로. 넘침과 다른 수거장의 지연 가능 |
| 배출 안내 활동 | 30 | 선택 현장의 방법 인지 기준을 2차부터 0.30 높임, 최대 0.95 | 이미 쌓인 봉투는 남고, 장소가 멀면 안내 뒤에도 투기 가능 |

정책마다 지도에서 세 후보 중 한 곳을 고른다. 취소는 이전 계획을 유지하고 **정책 시행**에서만 실제 실행에 반영한다. 세 정책 합계 110은 예산 100을 넘는다. 배출함의 12㎡는 현장 옆 지정 공간이며 시나리오 간 건설 상태는 누적하지 않는다.

## 모형 규칙

`DumpingSimulation`이 `WasteSimulation`을 확장한다. 일반 차량 140대·보행자 60명·수거차 2대와 정상 수거장 발생률을 공유한다. 공통 클래스에 추가 수거 지점·방문 순서를 받는 선택 설정만 추가했으며, 설정이 없으면 이전 수거 실험과 동일하다.

- 같은 시드는 같은 초기 투기물과 36건의 배출 수요(현장당 12건)를 만든다. 시각·양·방법 인지·거리 선택값을 정책 전후 공유하며 유리한 난수를 다시 뽑지 않는다.
- 가장 가까운 배출 장소까지 블록 직각 거리를 계산한다. 방법을 알고, 요청별 허용 거리 35~150m 안이면 정상 장소에 배출하며 그렇지 않으면 원래 현장에 투기한다. 안내·거리 기준은 교육용 가정이다. 모형 속 미인지·먼 거리로 인한 양을 현장 자료에 따로 기록한다.
- 기존 수거장 용량은 40봉투, 새 배출함은 16봉투다. 넘친 양도 같은 지점에 남아 수거 대상이 되며 다른 투기 지점으로 임의 이동시키지 않는다.
- 기존 수거차의 정차·수거·적재량 55봉투·하역을 공유한다. 실제로 해당 도로에 도착해 멈춘 뒤 초당 0.9봉투만 줄어든다. 작업자가 차에서 현장까지 운반하는 보행은 생략한다.
- 한 번 모두 치운 현장에 새로 버린 양을 **청소 뒤 재발**로 누적한다. 청소한 적이 없어 재발량이 0인 곳이 깨끗하다는 뜻은 아니다. 한 방문 뒤 다음 지점으로 이동하며 반복 순회는 생략한다.

항상 `초기량 + 새 발생량 = 현장 잔량 + 차량 적재량 + 처리장 하역량`이다. 현장 잔량은 `무단투기 + 지정 장소 안의 양 + 정상 배출의 넘침`으로 나눈다. 정책으로 목적지가 바뀌어도 전체 발생량은 같다. 임의의 만족도·감점은 사용하지 않는다.

## 비교와 기록

결과는 투기 잔량·새 투기·재발·넘침·기존 수거장 잔량·도시 전체 잔량·수거량·예산을 비교한다. 회차별 표, 세 투기 현장과 여섯 기존 수거장의 차이, 주민 의견은 필요할 때 펼친다. 다른 이웃의 수거가 늦어진 결과도 표시한다.

모형은 `illegal-dumping-v1`, 무단투기 저장은 v6다. 수요·목적지·까닭, 정책 위치, 회차, 수첩의 가설·선택 근거·수정안을 보존한다. 다시 열기·인쇄에도 기존 수거장별 변화를 포함한다. 다른 사례는 v5로 저장하며 v3/v4/v5도 계속 읽는다. 입력 기록은 위치·수요·비용·회차·물량 보존을 검사한다.

하천 유입·수질오염·강우, 주민 개개인의 배출 이동 애니메이션, 법률상 과태료·단속 기준은 포함하지 않는다. 다음 단계는 별도 수질오염 사례다.
