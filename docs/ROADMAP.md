## 알려진 한계

1. 같은 이동은 교차로 안에서 연속 추종하지만 서로 다른 상충 경로는 전체 구간을 예약한다. 직진 배출량은 공개 자료의 일반 범위와 비교했으며, 특정 지역의 현장 보정이나 출발 반응시간 보정은 하지 않았다. 도착 지점은 교차로 내부의 추상적인 목적지이고 주차장 진입 애니메이션은 없다.
2. MOBIL 기반 차로 변경은 현재 같은 방향 2차로 구간에 적용한다. 변경 중에는 관련 차로의 새 진입과 다른 변경을 보수적으로 제한한다. 3차로 이상을 연속 횡단하는 변경, 강제 끼어들기, 교차로 내부 변경은 지원하지 않는다.
3. 회전은 96개 구간의 호 길이 표를 이용한 수치 근사다. 상세 타이어·조향 모델은 없다.
4. 정해진 도시와 정책 지점만 지원한다. 주행 중 도로 삭제/편집, 범용 실시간 재경로 탐색은 제공하지 않는다.
5. 작은 화면에서는 정책·결과 정보창 안에 스크롤이 필요하다. 키보드로 모든 UI 버튼은 조작 가능하지만 3D 지도 자체의 완전한 비시각 대체 탐색은 없다.
6. 테스트 PC의 Chrome에서 검증했으며 학교의 실제 저사양 PC에서 FPS 측정은 아직 하지 않았다. 300대 검증은 300건 수요이며, 혼잡으로 일부는 진입 대기한다. 300대 동시 도로 주행을 보장한 검증은 아니다.
7. 번들을 분리해 크기 경고를 없앴으나 게임을 실행하려면 약 732kB의 JS가 필요하다. 성능 측정은 개발용 고정 카메라 장면이며 CPU 감속은 실제 저사양 GPU를 재현하지 않는다.
8. 효과음의 WAV 구조·파형 수치는 확인했으나 직접 청취 평가는 하지 않았다.
9. 실제로 움직이는 보행자는 네 지역의 정해진 단방향 경로만 지원한다. 시설 계획에는 별도의 전체 보도망 거리 계산을 사용한다. 양방향 보행 회피, 전체 주민 보행 애니메이션, 보행과 차량의 병행 신호는 미구현이다. 가상 환경 부담은 Phase 3에 추가했다. 물류는 Phase 4에 추가했다. 재정·멀티플레이·계정·서버·AI API는 아직 제외했다. 서버 저장 기능 없이 실험 결과를 직접 JSON으로 내려받는다.

## 다음 개발 우선순위

지도 면적 4배, 지구 분리, 하천·교량, 실제 외부 연결도로, 자원순환센터, 6개 공터의 면적·예산을 함께 고려하는 복수 시설 계획을 구현했다. 상세는 [도시 확장 기록](EXPANSION.md)을 참고한다. 하천 수질·오염 이동 모델은 후속 범위다.

1. **Phase 5 — 지역 홍보**: 행사 방문객 수요와 지역 자원. 자유 운영은 장기 범위다.
2. **수업·학교 PC 실측**: 교사·4학년 학생과 용어·글자 크기·15~20분 흐름을 검토하고 실제 iGPU 성능 측정. 교사용 정책·예산 제한 설정은 후속이다.
3. **모델 보정**: 실제 교통·수거·시설 이용·환경·물류 자료를 확보한 후 가상 파라미터와 비교. 현재 수치를 실측 성능으로 해석하지 않는다.
